# TheReplyte Catalog — Final Design Prompts (A4, 4 Pages)

Ready-to-paste prompts for ChatGPT. Use ONE prompt per chat, paste the whole
block, and attach the images noted at the top of each prompt. Each prompt is
fully self-contained (style rules + layout + exact text) so pages stay
consistent and nothing gets merged.

Brand colors (from the live website): teal `#00d8c7` → indigo `#4a42fc`
gradient, navy `#12142b` text, lavender `#f6f7fd` panels, borders `#e6e8f5`.

**Assets to gather first:**
1. TheReplyte logo — transparent PNG, high-res
   (`apps/thereplyte-landing/public/logo.webp` can be converted)
2. CloudIT logo — transparent PNG, ORIGINAL colors
3. WhatsApp QR code — pointing to `https://wa.me/94771696631`
   (any free QR generator, high-res, black on white)

**Tip:** AI image generators often garble long text. Keep the generated
design and fix the text in Canva, copying word-for-word from the EXACT TEXT
blocks in each prompt.
